# Product

## Register

product

## Users

Bot developers preview messages and Mini Apps while building screens, without a Telegram account or a running game server.

## Product Purpose

Render fixtures with Telegram Web A's existing interface so developers can judge their bot inside Telegram, save screenshots, and repeat the process in CI.

## Brand Personality

Practical, familiar, direct. Telegram supplies the surrounding interface while each fixture supplies its own content and identity.

## Anti-references

Do not redraw Telegram's interface or replace it with a generic dashboard. Game examples must demonstrate actual interaction rather than put a static picture behind controls.

## Design Principles

- Use the messages a bot sends as the input.
- Preserve Telegram's own rendering and Mini App frame.
- Keep application content separate from the preview tool.
- Make reference examples usable with touch and mouse.

## Accessibility & Inclusion

Use native controls and visible focus states in examples. Explain ownership through labels and shapes as well as color, and honor reduced motion without hiding fleet progress.
